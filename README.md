# FreshCart - E-Commerce Web Application

نسخة طبق الأصل 100% من متجر FreshCart بجميع مميزاته، تصميمه، صفحاته، وربطه مع الـ API الأصلي.

## كيفية تشغيل المشروع

المشروع يعمل حالياً بالفعل على جهازك عبر الرابط:
👉 **[http://localhost:5173/](http://localhost:5173/)**

لتشغيله يدوياً في أي وقت:
```bash
npm start
# أو
node server.js
```

---

## المميزات المتوفرة:
1. **الصفحة الرئيسية (Home):**
   - السلايدر الرئيسي (Main Slider) والبانرات الإعلانية.
   - سلايدر التصنيفات (Categories Slider) لعرض الأقسام بالصور.
   - المنتجات الحديثة (Recent Products) مع إمكانية البحث الفوري.
2. **المنتجات (Products):**
   - استعراض جميع المنتجات مع الأسعار، التقييم بالنجوم، وزر الإضافة للسلة والمفضلة.
3. **تفاصيل المنتج (Product Details):**
   - سلايدر صور المنتج، الوصف الكامل، السعر، والمنتجات ذات الصلة.
4. **عربة التسوق (Cart):**
   - زيادة ونقصان الكميات، حذف عنصر، تفريغ السلة، وحساب إجمالي السعر بدقة.
5. **قائمة الرغبات (Wishlist):**
   - حفظ المنتجات المفضلة مع مؤشر حي في شريط التنقل.
6. **إتمام الطلب (Checkout):**
   - الدفع أونلاين عبر بطاقات الائتمان (Stripe) أو الدفع عند الاستلام.
7. **نظام الحسابات (Authentication):**
   - تسجيل الدخول (Login)، إنشاء حساب جديد (Register)، واستعادة كلمة المرور (Forgot Password / Verify Reset Code).
